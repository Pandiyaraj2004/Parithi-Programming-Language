# Changelog — Parithi Language Support (VS Code extension)

## 0.1.0

- Initial release.
- Syntax highlighting for `.pr` files (`syntaxes/parithi.tmLanguage.json`), covering every keyword, operator, literal, comment, and built-in function documented in `docs/MASTER_DOCUMENT.md`.
- Language configuration (`#` line comments, bracket/quote auto-closing, `if`/`repeat`/`while`/`task` → `end` indentation).
- A "Parithi Icons" File Icon Theme showing the Parithi logo for every `.pr` file.
